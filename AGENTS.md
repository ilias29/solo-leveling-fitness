# Solo Leveling Fitness – project notes

## Layout
- `index.html` – markup + CSS; loads `src/ui/app.js` as an ES module (no bundler).
- `src/data` workouts & guides · `src/state` state + migrations · `src/logic` xp/hp/streak/dates · `src/storage` localStorage · `src/backup` export/import · `src/ui` rendering.
- `www/` is the Capacitor webDir. Generated by `npm run build:www` – never edit by hand, commit it after rebuilding.

## Commands
- `npm test` – unit tests (node:test).
- `npm run test:e2e` – Playwright browser tests (first time: `npx playwright install chromium`).
- `npm run serve` – local static server on http://localhost:8080.
- `npm run build:www` – refresh `www/`.

## Data rules (critical)
- localStorage key `soloState` holds all user data. Never call `localStorage.clear()` in app code, never drop fields.
- Schema changes go through `src/state/migrations.js` (bump `SCHEMA_VERSION`, add a step, add a fixture in `tests/fixtures.js`).
- Per-exercise data is keyed by exercise index – do not reorder exercises in `src/data/workouts.js` without a migration.
- Seed days 2026-10-14/15/16 must stay in `questDays`.
- XP values (kb 50, wall 20, stretch 15) and 300 XP/level must not change without approval.

## Android
- appId `com.ilias.sololevelingfitness` must not change.
- Release signing uses GitHub Secrets only. Never commit keystores or passwords. Do not change the signing key.
- When adding a new file under `src/`, also add it to `ASSETS` in `sw.js` and bump `CACHE`.
